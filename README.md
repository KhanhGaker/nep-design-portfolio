# Nếp — Concept Design Portfolio

Eight Vietnamese design concepts, with thirteen SVG designs created by an AI assistant at the user’s request. Fictional brands and events. No verified human design authorship, client work or Canva Creator approval is claimed.

Open index.html for the portfolio or review.html for the eight-page review layout. The PDF contains raster page previews, not an editable Canva template. Source SVGs are embedded in the HTML and available through each project’s download links.

No third-party photographs or font files are distributed. Typography relies on system fonts. See provenance.txt for scope.
